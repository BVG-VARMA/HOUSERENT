# 🏠 HOUSERENT

### House Rental Web Application

HOUSERENT is a web-based project designed to provide a simple way for users to explore and manage house rental information.

The project was developed as a practical learning project to understand how a web application can organize rental-related information and present it through a user-friendly interface.

---

## 📌 About the Project

Finding suitable rental houses can involve checking different properties, comparing available information, and keeping track of options.

**HOUSERENT** aims to provide a simple digital platform where rental property information can be presented in an organized way.

### 🎯 Main Objective

* Make rental property information easier to view
* Provide an organized interface for house listings
* Practice web application development
* Understand the process of building and structuring a complete project
